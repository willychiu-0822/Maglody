# Maglody 角色視覺設計（對齊真實音樂人線索）

目標：看起來像「會坐在錄音室裡的人」，不是柔焦插畫模特。

## 製作人 producer — 線索：Finneas 工作室日常 + Jack Antonoff
- 配件：黑色棒球帽、可選粗框圓眼鏡、手拿馬克杯或靠在椅背
- 穿著：洗舊黑色／圖騰短袖 band tee（不要米色厚毛衣）
- 髮型：帽簷下露出微亂短髮或中長碎髮
- 氣質：沉穩但像待了一整天的製作人；問「這像不像你要的感覺？」
- 避免：網紅柔光臉、完美髮絲、時尚大片pose

## 作詞人 lyricist — 線索：方文山（寫作者在場）+ 陳綺貞文青層次
- 配件：翻開的筆記本、鉛筆或鋼筆、可選細框眼鏡
- 穿著：簡單白襯衫或黑高領＋薄外套／素色針織（不要粉紅開襟可愛風）
- 髮型：俐落短髮或中長自然髮，偏實用、可工作整天
- 氣質：安靜細膩，像在找那一個對的字
- 避免：偶像劇女主感、過度妝感

## 作曲家 composer — 線索：工作室作曲／坂本龍一式素黑 + Finneas 耳機實作
- 配件：**頭上戴著**封閉式監聽耳機（黑／深灰，像 ATH-M50x），不是只掛脖子當裝飾
- 穿著：黑或炭灰素 T／高領，可加細鍊
- 髮型：微亂、像剛從琴邊抬起頭
- 氣質：溫和、愛哼，用聲音多於術語
- 避免：時尚耳機廣告感、過度甜美微笑

風格仍用：軟水彩＋紙質，但五官與穿著要「像真人音樂人」，比例寫實一點。

## 編曲 arranger — 線索：現場／編曲人俐落層次 + 耳機掛脖（角色 enter 原文）
- 配件：監聽耳機掛在脖子上、可拿平板或兩張小卡在比版本
- 穿著：深色外套／工裝感襯衫＋素 T，比製作人更俐落
- 髮型：乾淨短髮或側分，不亂到像剛睡醒
- 氣質：一次給你聽兩個版本；動作明確
- 避免：DJ 夜店感、過度潮牌 logo

## 錄音／混音 engineer — 線索：真實錄音室工程師（監聽耳機戴頭上、麥克風／線材）
- 配件：封閉式監聽耳機**戴在頭上**、麥克風架在身側或手邊線材、可選小手電筒／記號筆
- 穿著：黑色或深灰實用 T／polo、可有薄背心；口袋感
- 髮型：短髮實用，可輕微疲累
- 氣質：一次只說一件事；調架、聽相位、講步驟
- 避免：電競主播燈光臉、巨大混音台壓過人物
