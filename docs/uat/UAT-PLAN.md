# Maglody 新手使用者 UAT 計畫

本輪規格：產品負責人 2026-11-09 session B 指示。保留既有程式與 14 項單元／整合測試，直接在 codex/burn-b 執行。每輪先合併 codex/burn-a；視覺缺失交 A，功能缺失由 B 先重現再修復，逐項本機 commit。禁止 push、部署、tunnel、使用金鑰。

## 執行與驗收

`npm run test:e2e` 使用系統 Chrome（channel: chrome），桌面 1280×800、手機 390×844。Playwright 自行啟動 production preview 4111（strictPort、不重用外部 server），結束自動關閉。音訊使用 Chrome 假麥克風；相片使用 repo icon，API 一律攔截為受控錯誤或受控回應，不呼叫真服務。真麥克風、真人音色、實體手機與真 LLM 不在本輪驗證範圍。

每個案例獨立瀏覽器資料；功能結果必須由 UI 操作與可見結果驗證，storage 僅用來設定明列前置與檢查保存。UAT-03 從空白資料完整走過九檯，不預填專案。其餘下游案例以固定、非機密的完成歌曲作前置。每例在兩 viewport 都執行，總數以「案例 × viewport」計；任一失敗不得宣稱整體通過。R1/R4 的美感與真人相似程度不能只靠 DOM 證明，DOM 加截圖檢視並記錄限制。

每次 run 產生獨立 evidence/<run>/<viewport>/UAT-xx.png（主流程另有各檯截圖），失敗保留 trace。reporter 更新 UAT-RESULTS.md 與 UAT-STATUS.json，並將逐次結果寫至 evidence/<run>/results.json。只有所有案例通過且沒有未結視覺缺失才 ready_for_user_test=true。
