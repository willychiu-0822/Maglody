# 真實創作者的做歌流程，以及 Maglody 如何對齊

目標：讓使用者覺得自己是在**跟製作人一起待在工作室**，而不是在破關。使用者想成為真正的創作者，所以流程要貼近創作者／創作歌手的實際做法。

## 1. 研究摘要

### 1.1 三個階段：Generate → Shape → Refine

| 階段 | 創作者在做什麼 | 心態 |
|---|---|---|
| **發想 Generate** | 捕捉靈感：語音備忘錄、哼一段、寫幾個字、拍一張照；定主題、歌名、Hook | **零審查**。先求有，不求好；被遺忘的靈感幾乎找不回來 |
| **成形 Shape** | 和弦迴圈（和弦床）上亂哼（gibberish）找旋律 → 旋律定稿 → 填詞 → 排段落結構 → 編曲 | 組裝。用結構把素材串起來 |
| **打磨 Refine** | 錄 Demo → 試聽 → 改稿 → 再試聽 → 決定「完成」 | 有標準地挑剔，但敢說完成 |

- 捕捉要**快**，不要求精緻；備忘錄的任務是保存火花，不是好聽（[ScoreCloud](https://scorecloud.com/learn/capture-musical-ideas-fast/)、[Jack Righteous](https://jackrighteous.com/blogs/guides-using-suno-ai-music-creation/from-voice-memo-to-finished-song-using-suno-ai-step-by-step-workflow)）。
- 第一版 Demo 往往只有**草稿人聲、鼓、貝斯**；太早做高音質，反而不敢大改（[RingCentral UX](https://medium.com/ringcentral-ux/the-ux-of-songwriting-recording-9e2c126b7ac6)）。
- **先完成一份完整的爛草稿**：沒寫完的東西沒辦法改（[A3 Tunes](https://a3-tunes-3hm.pages.dev/blog/writing-a-song-step-by-step-guide-for-new-artists)）。
- **改稿要留版本**（demo 1、lyric pass A…），改壞了能退回，也記得為什麼改（[Gravitee 整理](https://gravitee.io/corpus/gen-1282/spring-wallows-ep/songwritingprocess.html)）。
- 先把語音備忘錄轉成文字，保留原本的節奏與意象，再進入歌詞改寫（[macmyths](https://macmyths.com/how-to-turn-a-voice-memo-into-finished-song-lyrics/)）。

### 1.2 常見的起點（不是只有一種）

1. **Vibe／主題 → 和弦迴圈＋哼唱 gibberish → 填詞**：最常見。
2. **詞先**：先有一段完整的話，再替它找旋律。使用者提到黃玠式的做法；公開訪談中能找到的是他的作品多半從生活經歷慢慢累積，並以吉他民謠 Demo 起稿（[報導者](https://www.twreporter.org/a/podcast-2024-04-23)、[Marie Claire](https://www.marieclaire.com.tw/entertainment/music/76665)），我們沒有找到他明確說「先寫詞」的出處，因此只把「詞先」列為一種起點，不歸給特定人物。
3. **旋律先**：腦中先冒出一段旋律，這也是 Maglody 預設的第 1 步。
4. **和弦先**：在樂器上找到一組好聽的迴圈，再往上哼。

### 1.3 非線性

真實的工作室不會照順序走：寫詞時冒出新旋律、編曲時想改副歌、半夜想到一句詞。工具必須：

- 隨時能記，記完回到原處，不丟上下文。
- 能跳到任何一步，前面沒做完也能先做後面。
- 一則靈感可以同時有字、聲音和圖。

## 2. Maglody 的對齊

| 創作者流程 | Maglody 的做法 |
|---|---|
| 三階段 | 旅程分成 **發想**（哼唱、構想）→ **成形**（和聲、旋律、歌詞、編曲）→ **打磨**（錄音、混音、檢討）；頁首與章節標題都會標出目前的階段 |
| 發想期零審查 | 發想期的回饋不出現紅燈，只有「可以試試」；並明確寫出「現在先不審查」 |
| 隨時捕捉（語音／哼／字／圖） | 底部「✎ 記一下」便條，一則靈感可以同時掛文字、語音（含聽寫）、哼唱（含音高分析）、照片 |
| 素材庫 | 「翻翻本子」：可拉進歌名、Vibe、某段歌詞、旋律種子，或「從這則開始一首歌」 |
| 多種起點 | 第 1 步上方的「今天從哪裡開始？」：哼一段／從一句詞／從和弦迴圈／從靈感本子 |
| 和弦床＋gibberish | 和聲章節可以循環播放和弦；旋律章節可以匯入哼唱當草稿 |
| 先有完整爛草稿 | 每一步的門檻都很低（「先這樣，之後還能改」），也可以先跳過；底部 ▶ 隨時播放**目前為止的 Demo**（有什麼放什麼） |
| Demo → 試聽 → 改 | 「存成 Demo 版本」：保存當下整首歌的快照，可以標註這版改了什麼，並隨時回到舊版 |
| 敢說完成 | 總檢討由使用者自己評分並寫下判斷；完成之後仍可回頭修改 |
| 製作人，而不是考官 | 大師旁白只在你做完之後說話，具體指出好在哪裡、下一步可以怎麼試；不代寫 |

## 3. 第一首歌的主題種子

靈感本子裡預設放了使用者的第一則真實靈感：**「負罪前行」**（主題／情緒 vibe，可能當歌名或核心意象）。

建議的示範路徑：

1. 按「✎ 記一下」或打開「翻翻本子」→「負罪前行」→「從這則靈感開始一首歌」。
2. 進入構想：歌名與 Vibe 已經放好。大師提示「負罪」的重量與「前行」的推進形成張力，建議試試小調、70–85 BPM。
3. 回到哼唱：心裡默念這四個字，哼一段 → 得到調性與和弦建議。
4. 和聲：排一組迴圈，循環播放，同時哼 gibberish → 旋律匯入 → 定稿。
5. 歌詞：依旋律音數填詞，「負罪前行」放在副歌的 Hook。
6. 編曲 → 存成 Demo v1 → 試聽 → 改 → Demo v2。
