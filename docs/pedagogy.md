# 教學設計：在工作室裡，邊做邊懂

Maglody 是一間**工作室**，不是課程或關卡：你可以把靈感、段落、哼唱東拼西湊成新作品，同時像跟在大師身邊一樣，做完才知道剛剛那叫什麼。真實創作者的流程見 [creator-workflow.md](creator-workflow.md)。

對象是完全沒學過樂理、頂多知道音階的人。他們想「跟著 vibe」自然創作，並把詞、曲、編曲一步步做完。

## 1. 研究結論

### 1.1 從情緒／vibe 出發的創作流程

- 多數新手教學建議**先定情緒，再選和弦或旋律去捕捉它**。先定情緒能縮小選擇範圍，也能讓內在批評先退場（[Taylor Davis](https://taylordavisviolin.com/blog-2/songwriting/how-to-write-a-song-professional-breaks-it-down/)、[Bridge to Music](https://bridgetomusic.com/simple-steps-for-beginner-song-composition-to-spark-your-creativity/)）。
- 只選**一個情緒核心**。新手常同時塞太多主題，歌會散掉（[sguru](https://sguru.org/?p=58074)）。
- **和弦是最快定調情緒的元素**；旋律則承載最多情緒（[Secrets of Songwriting](https://www.secretsofsongwriting.com/2017/04/03/why-so-many-songwriters-start-by-working-out-chords/)）。
- 「旋律先行」流程：先有一小段旋律，再找支撐的和弦，感受兩者組合出的情緒，最後寫詞（[Soundtrap](https://blog.soundtrap.com/?p=1382)）。在和弦循環上亂哼無意義音節，是找旋律的實用方法。

**落實到產品**：第 1 章是哼唱（旋律先行），第 2 章是 Vibe 板與情緒（把情緒變成大小調與 BPM）；之後每一章，大師都會拿「這像不像你的 vibe」來對照。

### 1.2 音階 → 旋律 → 和弦

- **五聲音階**拿掉大調的 4、7 級（沒有半音），幾乎怎麼排都好聽，最適合新手（[iZotope](https://www.izotope.com/en/learn/how-to-write-a-melody-for-your-chord-progression.html)、[Secrets of Songwriting](https://www.secretsofsongwriting.com/?p=7813)）。
- **動機**：先寫一個短樂句，重複一次，再改結尾或換起始音（[Icon Collective](https://iconcollective.edu/writing-melodies-tips)）。
- **留白**讓樂句能呼吸；目標是「一口氣哼得完」。
- 同一組五聲音階放在低音區給主歌、高音區給副歌，就能製造段落對比。

**落實到產品**：旋律格預設開啟「五聲安全區」；回饋會檢查強拍和弦音、級進與大跳、休止換氣、動機重複，以及副歌是否比主歌高。

### 1.3 中文歌詞與旋律

- 中文有聲調，**旋律走向要盡量順著字調**，否則會「倒字」，聽起來像別的字（[黃輔棠，世界日報](https://www.worldjournal.com/wj/amp/story/124497/8755150)、[HKBU 研究](https://scholars.hkbu.edu.hk/en/publications/unraveling-the-relation-between-mandarin-tones-and-musical-melody-11/)）。
- 中文流行歌通常**一字一音**；字數和音數對齊是第一步。
- 押韻用「十三轍」，韻母相近就算押韻。

**落實到產品**：歌詞排在旋律之後，大師會先告訴你「副歌有 N 個音，前兩句大約 N 個字」。回饋包含字數對稱、句尾韻腳顏色與一字一音對位；倒字放進最後檢查清單（「跟著伴奏唱一遍」），並在「為什麼」卡片裡解釋。

### 1.4 編曲層次

- 把歌畫成**能量曲線**：主歌低、導歌升、副歌最高、最後一次副歌前先收一下（[Soundbridge](https://soundbridge.io/en/how-to-arrange-a-song-a-guide-for-songwriters)）。
- 新手最常犯的錯是**第一段主歌就全員到齊**，副歌就沒有地方可以再往上了。
- 減法編曲：先讓所有東西都響，再從低能量段落拿掉（[Ableton](https://makingmusic.ableton.com/arranging-as-a-subtractive-process)）。

**落實到產品**：編曲章節用能量長條圖呈現每一段的樂器數量；回饋會檢查「副歌比主歌滿」和「中段有收」，每一段都能用 Web Audio 立即試聽。

## 2. 讓新手做得完、感覺有學到

| 參考 | 借用的原則 | 在 Maglody 的樣子 |
|---|---|---|
| Brilliant | 先動手解題，再給解釋；回饋在推理還新鮮時出現（[Brilliant](https://brilliant.org/resources/choosing-brilliant/how-brilliant-teaches-math/)） | 「為什麼」卡片在動手前不出現；完成後只亮一行「想知道？」，點開才有解釋與「▶ 用剛才的聲音再聽一次」 |
| Productive Failure | 「先解題、再教學」的設計，對概念理解的效果量 g≈0.37–0.58（[Sinha & Kapur 2021](https://www.x-mol.com/paper/1406031499744456704)） | 不先上課；先讓學生排和弦、寫旋律，回饋指出問題後再解釋原理 |
| Duolingo | 每一步都有即時回饋；進度看得見（[UX Collective](https://bootcamp.uxdesign.cc/language-learning-with-duolingo-the-interaction-and-instruction-ed5ac0029332)）。批評：連續天數可能取代真正的學習 | 綠／黃／紅短回饋；頁首的旅程線。不做連續天數、不做分數排行，避免為了衝紀錄而學 |
| Figma | 一個檔案從頭做到完成品 | 「我的歌」作品面板會隨章節長出來；每章結束都能聽到目前的歌 |
| Yousician／100Lights／Kiwisonic | 用耳朵和麥克風驗證，而不是只用眼睛 | 哼唱音高軌跡、跟唱調音針（±25 音分＝綠）、大小三和弦與終止式聽辨題、混音 A/B 比較 |

### 原則

1. **每完成一小步，就有聽得到的成果。** 每章底部都有「▶ 聽成果」：哼唱＋主音、情緒＋速度、和弦循環、旋律＋和弦、副歌配上詞（語音合成）、編曲前 4 段。完成章節時會自動播放一次。
2. **「為什麼」在做完之後才出現，並且用你剛才的聲音解釋；只點燃好奇，不灌輸**（見第 3 節）。
3. **進度看得見、可以回頭改、不鎖住創作。** 每一章隨時都能進去；若前面還沒完成，只會出現一則溫和提示。也有「先跳過，之後回來」。
4. **大師的語氣鼓勵但具體。** 不說空泛的「很棒」，而是說「你的副歌最後停在 D（V），這叫半終止，所以會想再聽一輪」。每章完成時會顯示「這一章你學到」，內容引用學生自己的作品。
5. **不代寫。** 大師可以提供和弦走向選項讓你試聽（材料），但歌詞只給韻腳字與引導問題；整句、整段、整首歌一律由學生寫。
6. **接住靈感、不打斷。** 任何章節都能按「記一下」紙條，存完還留在原地；靈感之後可以一鍵拉進歌名、Vibe、歌詞某一段或當旋律種子。

## 3. 學習是火種，不是灌輸

**核心原則：先做、先聽，之後才用剛才的聲音輕輕點一句為什麼；想深入的人自己往下挖。** 一開始不灌滿，不設術語牆。

| 層次 | 什麼時候出現 | 樣子 |
|---|---|---|
| 0. 動手 | 一開始 | 老師只說一句「先做什麼」，例如「哼一段給我聽，不用好聽」 |
| 1. 聽見 | 做完當下 | 立刻播放：你的哼唱＋主音、你的和弦循環、你的旋律 |
| 2. 火種 | 做完之後 | 一句話把剛剛那個聲音命名出來：「你最常回去的音是 G——它就是這首歌的家。」術語最多一個 |
| 3. 好奇才點開 | 學生主動點「想知道？」「多說一點」「我怎麼聽出來的？」 | 白話原理＋「▶ 用剛才的聲音再聽一次」 |
| 4. 再深一點 | 學生再點一次 | 「還能用在哪」：遷移到其他情境 |

具體做法：

- 「為什麼」卡片在動手前**完全不出現**；動手後只亮一行，不會自動展開。
- 老師的開場只有一句話，其餘放在「多說一點」。
- 回饋一次只說兩件事：一件做得好的、一件可以試的；其他收在「還有 N 則觀察」。
- 韻腳表、調性計算方式等小抄都預設收起。
- 發想期（哼唱、構想）不出現紅燈，只有「可以試試」。
- 大師旁白的「你學到」只命名一個概念，而且一定引用學生自己的作品（「你的副歌最後停在 D（V），這叫半終止」）。

判斷標準：**如果拿掉這段文字，學生還是做得下去，它就應該被收起來。**

## 4. 一條龍流程

```
哼唱解析 ─▶ 構想/Vibe ─▶ 和聲 ─▶ 旋律 ─▶ 歌詞 ─▶ 編曲 ─▶ 錄音準備 ─▶ 混音 ─▶ 總檢討
   │            │           │        │        │        │                         │
 調性/音域    大小調/BPM   和弦進行  匯入哼唱  依音數填詞  能量曲線 ─▶ MIDI ─▶ REAPER  自評，由你判斷
          ▲
     靈感庫（任何時候都能記，也能從任一則開始）
```

每一章的產出都是下一章的輸入：哼唱決定調 → 情緒決定大小調與速度 → 和弦是旋律的地板 → 旋律的音數決定歌詞字數 → 編曲用到前面所有素材。
