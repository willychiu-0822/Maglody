# UX 自測紀錄：完全新手、手機直向

## 方法

- **裝置**：Playwright 模擬 iPhone 13（390×844、觸控、`deviceScaleFactor` 3），Chromium 以假麥克風裝置提供音訊，並允許麥克風權限。
- **環境**：`npm run build` 後用 `vite preview` 測正式版。
- **自動檢查**：每一頁檢查水平溢出、小於 36px 的觸控目標、小於 12px 的文字、JS 錯誤。
- **人工檢查**：每一步都截圖，用「第一次打開、不懂樂理」的眼光檢查：看不看得出下一步該按什麼、文字讀不讀得動、有沒有被蓋住的東西、會不會卡住。
- **測試情境**：
  - A 主流程：哼唱（假麥克風＋示範哼唱）→ 構想 → 和聲（排 8 格＋聽辨 4 題）→ 旋律（匯入哼唱）→ 歌詞 → 編曲 → 隨手記 → 翻本子 → 從「負罪前行」開始 → 問大師「換一個更哀傷的走向」
  - B 突發靈感：一進來就記 → 同一則裡打字＋說話＋（錄音中）加照片＋哼一段 → 存檔 → 從 seed 開始 → 重新整理後資料仍在
  - C 工作室：三階段、四種起點、勾 3 則拼成一段歌詞、存成 Demo v1
  - D 後端：OpenAI Chat／OpenAI Responses／Gemini API／Vertex AI 四條路徑，用本機假端點驗證請求格式、授權標頭與輸出淨化；缺金鑰時的錯誤訊息

## 驗收清單

規則：沒有通過的項目不能標 done。

| # | 項目 | 狀態 | 證據／說明 |
|---|---|---|---|
| 1 | **手機可直接用** | ✅ done | 情境 A 在 390px 寬的模擬手機上從頭走到尾，0 個 JS 錯誤、0 個水平溢出。所有控件 ≥ 36px，觸控裝置上主要按鈕 ≥ 44px。可安裝為 PWA（manifest＋service worker）。⚠ 尚未在實體 iPhone／Android 上測試；Safari 的麥克風與 `audioSession` 行為需要真機確認。 |
| 2 | **多模組靈感可以疊加**（字／說／哼／拍） | ✅ done | 情境 B：同一則靈感同時有文字、語音 0:02、哼唱 5 音 · G 大調，以及 1 張照片（照片是在錄語音的過程中加進去的）。媒體存在 IndexedDB，重新整理後仍在。⚠ 語音聽寫依賴瀏覽器的 Web Speech API；假麥克風下無法驗證辨識結果，Firefox 不支援。 |
| 3 | **工作室拼貼，而不是關卡** | ✅ done | 任一檯都能直接進入，沒有鎖。有「先跳過」，跳著做時只會出現溫和提示。頁首分成「發想／成形／打磨」三段。第 1 檯提供四種起點。情境 C：勾 3 則靈感 →「拼成一段新歌詞」→ 自動進入歌詞檯並填入 3 行；哼唱可以接成一條旋律種子。可存 Demo 版本、試聽並回到舊版。文案從「章、關」改為「檯」。 |
| 4 | **繪本感、輕柔，沒有 AI 感** | ✅ done | 紙、墨、淡彩 tokens；按鈕是手繪墨線框；隨手記是貼在角落的便條紙；沒有漸層、玻璃、機器人圖示、分數或徽章。對照 docs/design.md 的禁止清單逐項檢查。圖示已換成紙墨風。⚠ 楷體／明體依賴裝置已安裝的字型，沒有另外載入網頁字型（為了離線與速度）。 |
| 5 | **悄悄地學，不硬塞知識** | ✅ done | 「為什麼」在動手前完全不出現；動手後只亮一行「想知道？」，不會自動展開；「還能用在哪」藏在第二層。老師開場只有一句話，其他放在「多說一點」。回饋一次只顯示 2 則（一個做得好、一個可以試），其餘收在「還有 N 則觀察」。韻腳表、調性計算方式都收合。發想期不出現紅燈。 |
| 6 | **接住突發靈感（含「負罪前行」）** | ✅ done | 底部「✎ 記一下」在每一檯都看得到，按 Alt+I 也能開。存檔後仍停在原本那一檯（情境 A：在「編曲」記完，提示寫「收好了。你還在『編曲』」）。seed「負罪前行」首次開啟就在本子裡；「從這則開始」會帶入歌名與 Vibe，大師依字義建議小調、70–85 BPM。若目前的歌已有進度，會先詢問，不會默默覆蓋。 |
| 7 | **用 ChatGPT／GCP，不用 Claude API** | ✅ done | 程式碼中沒有 Anthropic SDK 或 Claude 呼叫（已 grep 確認）。情境 D：OpenAI Chat Completions、Responses、Gemini API、Vertex AI 四條路徑都在本機假端點上通過格式與授權標頭檢查；不合法的 action 會被淨化掉；缺金鑰時會印出清楚的錯誤並結束。⚠ 尚未用真實 API 金鑰呼叫正式服務。 |
| 8 | **可以推到 Maglody repo** | ✅ done | `origin = github.com/willychiu-0822/maglody`，`feature/music-lab` 分支已成功推送多次；`main` 是初始 commit。 |
