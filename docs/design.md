# 視覺與文案設計：紙、墨、淡彩

## 第一原則：一屏一個主動作（2026-11 改版）

使用者回饋「太複雜、沒有主次、按鈕太多」之後，下面這幾條優先於本文件的其他規則。

1. **當下畫面只允許 1 個主動作**（`.primary-action`：滿寬、淡彩、墨線、明體字），**最多再加 1 個次要動作**（`.link-btn`：文字連結，不做成按鈕）。
2. **前進按鈕只在做完時出現**，而且會「取代」主動作的位置，例如「地板鋪好了，去旋律 →」。沒做完時畫面上不會有「下一步」。
3. **進階功能一律收進「＋ 工具箱」**，預設關閉：調性選擇、範本、回饋清單、原理、匯出、拼貼等都放在這裡。
4. **常駐元素只有兩個**：左上的「工作室 ▾」選單（檯位、我的歌、Demo 版本、REAPER、重新開始），以及右上的「✎ 記一下」貼紙。不要有底部導覽列、旅程列、浮動的大師列。
5. **靈感貼紙展開前不出現任何媒體按鈕**；展開後是一張紙、三個小圓（說／哼／拍），加上一個主動作「夾進本子」。
6. **工作區不算按鈕**：和弦色票、旋律格、情緒紙片、樂器紙片是「材料」，可以有很多個；但它們周圍不能再放其他行動按鈕。
7. **一屏只有一句大字**：這一檯當下該做的事。夥伴的旁白是頭像旁的小字，14 秒後淡出。

### 每一檯的層級

| 檯 | 一句話（大字） | 工作區 | 主動作 | 次要 |
|---|---|---|---|---|
| 哼唱 | 哼一段腦中的旋律給我聽 | 音高軌跡 | ● 哼一段 →（做完）用這段繼續 | 沒有麥克風？聽示範 |
| 構想 | 想帶著什麼感覺？ | 6 張情緒紙片＋一句話 | （做完）帶著這句話，去和聲 | ▶ 再聽一次這個感覺 |
| 和聲 | 點一個和弦聽聽 | 4 格＋6 個和弦 | ▶ 循環聽 →（做完）去旋律 | 換副歌 |
| 旋律 | 先把哼唱倒進格子裡 | 一小節的格子 | 用我的哼唱當草稿 → ▶ 循環聽 → 去歌詞 | 換副歌 |
| 歌詞 | 主歌。先寫你看到的畫面，大約 N 個字 | 一頁橫線紙 | ▶ 聽詞配旋律 → 去編曲 | 換副歌 |
| 編曲 | 先排出段落 | 能量長條＋5 張樂器紙片 | 排一個常見的骨架 → ▶ 試聽 → 去錄音 | — |
| 錄音 | 先確定最大聲時不會破音 | 音量條 | ● 測音量 | 沒有麥克風，先跳過 |
| 混音 | 把主旋律推到最清楚 | 4 條推桿 | ▶ 播放副歌 | 聽聽沒混之前 |
| 總檢討 | 這次換你當老師 | 我的歌＋一段自評 | ▶ 從頭聽我的歌 | 下載 MIDI，帶進 REAPER |

## 工作室夥伴

一屏只出現**一位**夥伴：頭像是墨線圈裡的一個字（製、曲、詞、編、錄），旁邊是一句斜體的登場句（「作曲家在琴邊坐下。」）或剛說的話。點頭像就能聊；在對話視窗裡可以切換成任何一位夥伴，不受目前檯位限制。

| 夥伴 | 預設出現在 | 專長 |
|---|---|---|
| 製作人 | 構想、總檢討 | 方向、vibe、段落起伏、什麼時候算完成 |
| 作曲家 | 哼唱、和聲、旋律 | 哼唱、調、和弦、旋律 |
| 作詞人 | 歌詞 | 一句話、畫面、押韻、字和旋律咬不咬得合 |
| 編曲 | 編曲 | 段落、樂器進場、能量 |
| 錄音師 | 錄音、混音 | 音量、暖嗓、混音、REAPER |

不要一次排出一整排角色按鈕；角色選擇只出現在對話視窗裡。

## 想要的感覺

像一本攤開在桌上、畫了一半的繪本，或一本創作筆記。目標是讓人文思泉湧時想立刻把東西放下來，而不是去操作一個產品。

- **藝術家的工作桌**，不是儀表板。
- **輕柔、留白、手感**：紙的纖維、墨線、水彩暈染。
- **情緒安全**：沒有分數、沒有排行、沒有刺眼的紅燈；「還不行」用淡彩說，並附上下一步。

## Design tokens（`src/styles.css` 的 `:root`）

| Token | 淺色 | 意象 |
|---|---|---|
| `--bg` | `#f4efe4` | 生宣紙；疊一層極淡的紙纖維雜訊 |
| `--paper` | `#fbf8f1` | 白報紙，卡片底 |
| `--ink` | `#2f2b26` | 松煙墨，文字與線條 |
| `--muted` | `#7b7468` | 淡墨，次要文字 |
| `--line` | `#e2d9c8` | 鉛筆線 |
| `--accent` / `--accent-soft` | `#b5634b` / `#efd6cb` | 朱砂與它的暈染，只用在「現在」與主要行動 |
| `--wash-ochre` / `--wash-indigo` / `--wash-sage` | 赭黃／藍染／青草 | 淡彩底，用在老師旁白、學到卡片、提示 |
| `--good` / `--warn` / `--bad` | 青苔／赭石／胭脂 | 回饋點，全部降低彩度 |

深色模式是「夜裡的紙」：暖色的暗（`#1d1a16`），不是螢幕黑。

**字體**：內文用手寫感楷體（Iansui、霞鶩文楷，沒有時退回系統黑體）；標題用明體／宋體（Noto Serif TC、Songti）。字距略寬，行高 1.8。

## 元件語言

- **按鈕**：1.5px 墨線、透明底，圓角四角不對稱，像手畫的框。主要行動用朱砂淡彩底加墨線，**低對比**，不用實心大色塊。不能按時改成虛線框。
- **卡片**：紙張、淡邊、幾乎沒有陰影。
- **老師旁白**：淡彩暈染的紙片（左上赭黃、右下藍染），頭像是墨線圈裡的「師」字，不用機器人圖示。
- **工作室選單**：左上一行「Maglody　哼唱解析 ▾」，點開才看到檯位（依發想／成形／打磨分組）、我的歌與 Demo 版本。
- **隨手記入口**：右上角一張用紙膠帶貼著、下緣撕過的黃色便條紙，微微傾斜，寫著「✎ 記一下」。錄音中會變成淡胭脂色。
- **隨手記面板**：筆記本頁。頂端一排線圈孔，輸入區是橫線紙、明體大字；三個大按鈕「說／哼／照」用虛線框。存檔按鈕寫「夾進本子，回去繼續」。
- **回饋**：淡彩底色的小紙片，搭配一個顏色點，不用警示燈和圖示。

## 文案語氣

- 像一位溫和的老師或製作人在旁邊說話，不像系統訊息。
- 具體：指出你做了什麼、那叫什麼、為什麼好聽。
- 不催促：用「先這樣，之後還能改」，不用「完成任務」。
- 靈感相關的文案要降低門檻：「幾個字就好」、「不用完整、不用好」、「它也許是（可不選）」。

## 禁止清單

以下元素一律不用。新增 UI 前請先對照這份清單。

| 禁止 | 原因／替代 |
|---|---|
| 紫藍漸層、霓虹漸層、彩虹漸層 | 通用 AI／SaaS 識別。改用淡彩單色暈染 |
| 實心高飽和大按鈕、膠囊型漸層 CTA | 太像「產品功能鈕」。改用墨線框＋淡彩底 |
| 玻璃擬態（backdrop-filter 模糊、半透明卡片） | 改用不透明的紙 |
| 大範圍、多層、彩色陰影 | 最多一條極淡的落地陰影 |
| 機器人、星星閃光（✨）、魔杖、大腦等 AI 圖示 | 用文字、墨線、手繪符號（✎、師） |
| 對稱的 KPI 儀表板、數字卡牆、圓環進度 | 「我的歌」放在工作室選單裡 |
| 分數、連續天數、徽章、排行榜 | 會把注意力從作品移開。改用「你學到」與可聽成果 |
| 刺眼的紅色錯誤框、警告三角形 | 用胭脂淡彩加一個具體的下一步 |
| 「AI 幫你生成」、「一鍵完成整首歌」類文案 | 違反「教練不代筆」原則 |
| 純黑 `#000` 背景、冷灰 UI | 用暖色紙張與夜晚的紙 |
| 過多 emoji 當圖示 | 介面只用少量墨線符號 |
| **一屏多個 CTA**（兩顆以上實心或框線按鈕並排） | 1 個主動作＋最多 1 個文字連結；其他收進工具箱 |
| **同時多個焦點**（大標題＋老師段落＋起點卡片＋旁白列＋導覽同時出現） | 一屏只有一句大字和一個工作區 |
| **儀表板式版面**：旅程節點列、階段列、多張結果卡、數字格 | 檯位放進「工作室 ▾」選單 |
| 常駐底部列（大師列＋播放鍵＋靈感鍵並排） | 只留右上角「記一下」貼紙 |
| 未完成就顯示「下一步／下一章」 | 做完才出現，而且取代主動作 |
| 一排 NPC／角色按鈕 | 一次只出現一位夥伴；切換角色只在對話視窗裡 |
| 預設展開的說明、回饋清單、範本 | 預設收在工具箱 |
